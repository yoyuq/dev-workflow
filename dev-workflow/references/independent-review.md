# 独立审阅节点

runtime 增加 `reviewer`，使用和 worker 相同的 harness 配置格式，但每次启动全新进程、上下文、报告目录和审阅 worktree。`review.max_rounds` 控制整个运行的审阅上限，耗时计入原运行预算。默认是（原任务数 + 预先允许的新增任务上限）× 实施尝试数 × 2；修订不会继续扩大此上限。审阅程序摘要改变会阻塞，不能静默换版本。

执行顺序：工作者结束 → 外部检查 → 本地任务提交 → 独立需求/代码质量审阅 → 必要人工签收 → 候选集成及检查 → 整分支独立终审 → 最终验收及需求覆盖报告。

审阅者读取 controller 生成的 context.json，输出 report.json。报告绑定提交、任务、约定版本及计划修订；阻断意见要提供负责的任务、真实文件/行号、spec/quality 分类及影响。无报告、错误绑定、进程失败、修改被审查代码均不能通过。结构校验只保证报告有效，不能证明模型判断正确。

阻断意见回传给负责工作者，使用剩余尝试预算修复，依赖成果重新验证。人工签收不能被模型审阅代替。报告列出实际检查；项目的浏览器、API、数据库检查应放入固定 verification/integration_checks，不能把“建议检查”写成已通过。终审之后仍执行最终独立检查。

范围内可复现的输入导致崩溃/HTTP 5xx、数据损坏或违反需求，即使原用例全部通过，也应为 blocking。报告保留触发输入、代码路径、后果，并区别真实复现与源码推断。新的反例随意见进入修复，不悄悄修改旧运行的固定验收；必要时在明确的新运行中增加外部反例检查。模型严重程度判断仍可能出错。

源码 worktree 按只读职责提供，原生 Codex 以单独报告目录作为可写沙箱根；控制器额外检测源码修改。Claude/command 和同用户进程的文件权限不构成强隔离。生产部署需要服务账户/容器及只读挂载隔离控制状态，不能仅靠提示词防止恶意工作者。

审阅不可用保留已提交代码并阻塞，状态、原因和报告都可查看。恢复独立审阅使用统一入口 `retry-review --task TASK`，消耗原剩余审阅预算；不得伪造批准报告。


## 减少重复审阅

控制器准备 `changes.patch` 和 context.json：任务差异从本次 `launch_base` 开始，终审差异仍覆盖原始基线到整分支；保留全量需求、共享约定、相关依赖、固定检查命令与真实结果。补丁只是导航，不能限制对受影响调用方的审查。旧记录没有 launch_base 时仍使用原始基线。

修复复审携带上轮阻断反例及报告摘要/哈希；终审携带各任务已完成检查和原审阅报告。报告有明确提交/约定/修订绑定，旧批准不能当作新提交的批准。遇到证据被改写直接阻塞。原报告、进程耗时、输入字节数、上下文与补丁摘要均保留，便于比较开销。

审阅先批量读取相关源码与检查入口，执行合适的独立基线、修复反例及源码暴露的新风险检查。通过且输入未变的命令不无故重复；出现失败、未覆盖需求或未解决风险才扩大验证。沙箱可执行性只探查一次；宿主通过不代表审阅沙箱可执行，缺失验证必须明确记录，不能伪造通过。不得以提速为由调低模型、跳过独立任务审阅/整分支终审、改固定检查或缩短审阅预算。

复现阻断问题后先写入 `changes_requested` 报告，再完成其余审阅并定稿；中途退出、超时或取消的报告保留诊断价值，但不能作为批准。明确落在依赖模块的问题可以按 task_owners 指向实际责任任务，总控回传该任务并使其下游成果重新验证。审阅上下文和补丁被改写同样阻塞验收。


## 只读审阅的看护

2.13 起，独立 reviewer 使用 read-tools 看护：不同 ID 的 SDK 成功工具完成（Codex command_execution completed 且整数 exit_code=0；Claude 非错误 tool_result）可以延后空闲截止。思考、心跳、失败工具、重复 ID 都不能延后。实现 worker 保持 artifact 看护；总运行与单次硬时限、固定验收、源码不变检查及审阅约束均保留。工具完成仅是操作进度，不能当成审阅结论或代码通过的证据。日志记录 watchdog_policy 和 successful_tool_observations。

原运行在最终审阅中因看护终止时保留 partial 及证据，不改旧 pins。补充运行的 review.base_commit 可固定为其 base_commit 的更早祖先，以便整分支审阅包含前一运行继承的改动；需给出完整 commit SHA，建上下文时核对祖先关系。任务审阅仍从任务 launch base 起，范围、预算与验收不因扩大只读审阅起点而改变。补测结果与原失败分开报告。
