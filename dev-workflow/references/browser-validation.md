# 浏览器流程验证

复用项目的 Playwright、Cypress 或宿主浏览器工具，先确认前后端服务与测试数据就绪。记录实际浏览器、视口、代码状态和入口路径。

围绕验收条件验证真实用户路径：输入与提交、加载、成功/失败反馈、刷新后的状态、相关权限与边界。使用稳定定位和有业务意义的断言；固定 sleep、仅等待 networkidle 或仅截屏不能代替成功条件。

功能检查与视觉检查分别记录。前后端联调使用实际接口；mock 检查的结论只适用于 mock 范围。保留必要日志、失败截图和可复现步骤，避免包含凭据或真实敏感数据。

设置有界等待，仅清理自己启动且确认身份的服务。将有复用价值的流程固化到项目已有测试方式，绑定验收 ID。浏览器或环境不可用时保留未验证项及恢复步骤，不以阅读代码冒充运行验证。
